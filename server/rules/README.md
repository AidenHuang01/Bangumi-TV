The server independently implements the XPath rule format and the subset of API
rules needed by sorani. It is not the Kazumi Flutter application and does not
implement every Kazumi feature. Rules are a fixed snapshot, not auto-updated.
Provider availability, catalogue accuracy, codecs and access rights are not guaranteed.

Added `7sefun` after a live Mac check on 2026-10-09: 葬送的芙莉莲,
episode 1, **Source 4** resolved to MP4 and returned original video bytes through
the Mac proxy (HTTP 206). Source 2 failed with HTTP 404. `akianime` was tested
but not added because its search site's TLS connection failed from this Mac.
This check is not a guarantee that every episode or playback source works;
physical-TV decoding still needs confirmation.
